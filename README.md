# Grace Church — React Template

A complete responsive React + Vite template for a church website.

## Included pages
- Home
- Saint History
- Church History
- Founder History
- Fathers & Sisters directory

## Responsive
Designed for mobile, tablet, mini-laptop, laptop and desktop widths.

## Footer location
The footer includes editable latitude and longitude values plus a Google Maps link.

Edit the values in:
`src/data.js`

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Customize
Replace:
- Church name/address/contact
- Latitude/longitude
- Saint data
- Founder data
- Fathers & Sisters
- Timeline entries
- Images

The current data is placeholder/demo content. Verify and replace historical claims before publishing.
